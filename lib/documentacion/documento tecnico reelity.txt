1. Visión general de REELITY (producto)

REELITY es una app móvil donde:

Un grupo pequeño de amigos crea su propio “reality show privado”.

Cada reality se organiza en temporadas (7, 14, 30 días…).

Cada día hay un reto en vídeo corto (10–20s) que todos pueden grabar.

Ves los clips de tus amigos, reaccionas y mantienes un streak de grupo.

Puedes buscar personas y comunidades para unirte.

Filosofía

Todo es gratis al inicio (modo “La red social”).

Objetivo principal: uso diario y adicción sana:

La gente entra todos los días a ver qué han subido sus amigos

y a subir su clip del reto del día.

Monetización = 100% futura. No se muestra nada de precios ni “Plus” ahora.

3.2. Idea clave: “fake backend”

Definimos repositorios abstractos, por ejemplo:

abstract class AuthRepository {
  Future<User?> login(String email, String password);
  Future<User> register(String name, String email, String password);
  Future<void> logout();
}

abstract class SeasonsRepository {
  Future<List<Season>> getSeasonsForUser(String userId);
  Future<SeasonDetail> getSeasonDetail(String seasonId);
  Future<void> uploadVideo({
    required String seasonId,
    required DateTime day,
    required String filePath,
  });
}


En esta fase, implementamos solo las versiones fake:

class FakeAuthRepository implements AuthRepository { ... }
class FakeSeasonsRepository implements SeasonsRepository { ... }


Más adelante, cuando tengas Spring Boot, creas:

class ApiAuthRepository implements AuthRepository { ... }
class ApiSeasonsRepository implements SeasonsRepository { ... }


Y cambias la inyección de dependencias. La UI no cambia.
